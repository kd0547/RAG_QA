# C2-P3 검토 화면에 실행 이력 전체

## 변경 파일
- `storage/schema.sql`, `repository/repo_connect.py`: `run.label TEXT` (기존 DB는 ALTER)
- `repository/evidence_repository.py`: `start_run(…, label=None)`, `runs_for_owner(owner_type, owner_id)` (시작 순서, `tool_calls` 목록, `seconds` 계산)
- `agent/agent.py`: `_invoke_logged`의 `label`을 `start_run`에 전달
- `app/routers/mails.py`: 응답에 `runs: [{run_id, label, status, started_at, seconds, tokens_in, tokens_out, tool_calls}]`. `trace`는 호환용으로 유지
- `frontend/src/mail/types.ts`: `MailRun`
- `frontend/src/mail/pages/MailReviewPage.tsx`: `AgentRuns` 컴포넌트. 실행별 접이식 묶음, 머리줄 `1차 초안 · 도구 3회 · 6.5초 · 입력 19,584토큰`, 최신 실행만 펼침, 도구 0회 + 정상 실행은 "이전에 읽은 근거로 재작성", 실패·한도는 빨간 표시
- `tests/test_mail_detail_trace.py` 3건 추가, `tests/test_mail_list.py` 응답 키

## 결정한 것
1. **머리줄 이름은 label 앞부분으로 정한다:** `메일 반려 반영` → "반려 반영", `메일 재시도`(P5) → "다시 생성", `메일 이어서 실행` → "이어서 실행 (재시작 복구)". 그 외는 첫 실행 "1차 초안", 이후 "N차 실행".
2. 머리줄에 입력 토큰 수도 넣었다 (지시서 예시에는 없음. 담당자가 비용 차이를 볼 수 있게).
3. 도구 0회인데 실패·한도로 끝난 실행은 "도구를 부르기 전에 끝남"으로 구분했다.
