# C2-P2 한 페이지가 길 때 이어 읽기

## 변경 파일
- `tools/tool.py`
  - `read_page_texts(…, offset=0)`: 첫(유일한) 페이지를 `offset`번째 글자부터 보여 준다. 잘린 페이지 항목에 `page_chars`, `next_offset`. offset이 페이지 길이 이상이면 빈 본문 + 안내 `message`. 잘림 안내 문구를 "잘린 페이지(next_offset 있음)는 그 페이지 하나만 offset=next_offset으로 다시 읽으면 이어집니다"로
  - `read_pages(…, offset=0)`, `read_attachment(…, offset=0)`: 페이지가 정확히 1개가 아니면서 `offset > 0`이면 `{"error": "offset은 페이지 하나를 읽을 때만 쓸 수 있습니다"}` (`read_attachment`는 pages를 비워 둔 경우도 오류). docstring Args·Returns에 offset·next_offset 설명
- `tests/test_long_page_offset.py`(신규)

## 결정한 것
1. 여러 페이지를 읽다가 중간 페이지가 잘린 경우에도 `next_offset`을 붙인다 (그 페이지 하나만 offset으로 다시 읽으면 이어진다). 지시서의 "잘린 페이지 항목"을 모든 잘림에 적용했다.
2. offset을 준 항목에는 `offset` 키를 넣어 어디서부터 읽었는지 보이게 했다.
3. `MAX_READ_CHARS`(20,000), DB 프롬프트는 바꾸지 않았다 (지시서 3장).

## 확인하지 못한 것 / Gemini에게 요청할 검증
- 실제 모델이 `next_offset`을 보고 같은 페이지를 이어 읽는지는 실모델로 확인해야 한다 (안내는 docstring과 결과 `message`에만 있다).
- 개발 서버의 `SSD_성능_비교.xlsx`가 실제로 한 페이지에 49,933자인지 시트별로 나뉘어 있는지는 확인하지 못했다 (로컬 DB에 없음).
