# C2-P8 내용이 없는 첨부를 매번 다시 파싱하지 않게

## 변경 파일
- `tools/tool.py`
  - `EMPTY_ATTACHMENT_MARKER = PageText(page=0, text="")`. `attachment_page_texts`가 메일 첨부를 처음 파싱했는데 결과가 비면 이 표시 행 하나(`seq=0, page=0, text=''`)를 저장하고, 읽을 때는 `page=0`이면서 본문이 빈 행을 뺀다
  - `read_attachment`: 페이지가 없으면 `{"error": "이 첨부에서 추출된 텍스트가 없습니다"}`

- 메시지 안내 줄의 페이지 수는 기존 계산(`len(…)`) 그대로 0이 된다.
