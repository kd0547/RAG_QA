# C2-P6 웹 질문의 대화·근거 정리

## 변경 파일
- `agent/agent.py`: `run_agent`·`run_agent_temp_attachments`를 `try/finally`로 감싸 `_cleanup_ask_thread(agent, thread_id)` 호출. `ask:`로 시작하는 대화만 `checkpointer.delete_thread()`와 `_thread_locks.pop()`. `task:`는 바로 반환. 삭제 실패는 WARNING만
- `repository/evidence_repository.py`: `purge_sessions(older_than_days) -> {"evidence", "evidence_use", "run"}` — `owner_type='session'`이고 `created_at`/`started_at`이 기준보다 오래된 근거·실행과 그에 걸린 사용 기록 삭제
- `config.py`: `SESSION_EVIDENCE_RETENTION_DAYS=14`
- `main.py`: lifespan에서 `mark_stale_sending()` 다음에 한 번 호출, 건수 INFO
- `tests/test_threads.py`: C1의 "ask 대화 2개가 남는다" 테스트를 "새 대화 2개를 쓰고 끝나면 0개"로 바꾸고 실패 경로 테스트 추가. `tests/test_evidence.py` 2건 추가

## 결정한 것
1. C1 테스트(`test_ask_uses_new_thread_each_call`)는 P6과 반대되는 동작(대화가 남음)을 확인하고 있어 P6 기준으로 고쳤다. 호출마다 다른 `ask:` ID를 쓰는지도 함께 확인한다.
2. 근거 사용 기록은 "오래된 session 실행에 걸린 것" 또는 "오래된 session 근거를 가리키는 것"을 지운다.
