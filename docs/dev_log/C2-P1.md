# C2-P1 발송 중 서버가 꺼진 작업 정리

## 변경 파일
- `repository/task_repository.py`: `mark_stale_sending() -> int`. 한 트랜잭션에서 `sending` 작업마다 가장 최근 발송 시도(`MAX(send_id)`) 중 `outcome IS NULL`인 행에 `send_unknown` / `서버 재시작으로 발송 결과를 확인할 수 없음`을 남기고, 작업 상태를 `send_unknown`으로. `reset_processing` docstring 수정
- `main.py`: lifespan에서 `reset_processing()` 다음에 호출, 건수가 있으면 WARNING. 주석을 "pending/drafted로 되돌리지 않고 send_unknown으로 넘긴다"로
- `entity/type.py`: `SENDING` 주석
- `frontend/src/mail/pages/MailReviewPage.tsx`: `sending` 안내 문구 (재시작하면 "전송 확인 필요"로 바뀐다고)
- `tests/test_mail_send_status.py`: 3건 추가

## 결정한 것
- 이미 결과가 있는 이전 발송 시도(예: `send_failed`)는 덮어쓰지 않는다. 가장 최근 시도가 결과 없음일 때만 채운다.
- 검토 화면 `sending` 안내의 "오래 남아 있으면 재시작된 것일 수 있다"는 이제 사실이 아니라서 문구를 고쳤다 (지시서에 없음, 상태 의미가 바뀐 데 따른 문구 정리).
