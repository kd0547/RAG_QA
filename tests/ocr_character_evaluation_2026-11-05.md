## 결과 해석

PaddleOCR-VL은 누락 1,030자가 가장 큰 오차입니다. 11쪽에서 1·2차 변경 이력과 모델 목록을 놓쳤고,
6쪽 첨부 제목, 13쪽 변경발급 제목, 여러 쪽의 로고 문자를 누락했습니다.
11쪽은 정답 1,872자 중 452자 오류로 정확도 75.85%입니다.

기존 LLM은 삽입 345자가 주요 오차입니다. 5·9쪽의 강조 설명, 9쪽 바닥글 중복,
마스킹한 17·21쪽의 캡션 중복, 19쪽의 빈 사진 영역 설명이 포함됩니다.
실제 오인식으로는 1쪽 `신고번호→신청번호`, `이면기재→이연기재`, 2쪽 `인증융합센터→인증종합센터` 등이 있습니다.

문자 전사 전용 LLM은 기존 프롬프트와 별도의 실험입니다. 총 오류는 155자로 줄었지만,
1쪽 한글/영문 항목명과 값의 출력 순서가 정답 순서와 달라 그 쪽은 86.72%입니다.
문자 내용이 같더라도 순서가 다르면 CER에서 삭제/삽입 또는 치환이 발생합니다.
기존 앱의 프롬프트를 이 실험 프롬프트로 변경하지는 않았습니다.

이 결과는 한 개의 인증서와 현재 모델/프롬프트/옵션에 한정됩니다. 반복 행이 많은 문서이므로 전체 평균이 높아도
한 문단이 통째로 빠질 수 있습니다. 페이지별 표와 누락 수를 함께 판단해야 합니다.

## 평가 범위와 재현 조건

- 대상: `tests/data`의 KC N5800 인증서 PDF 전체 21쪽. 표본 체크포인트 점수가 아닙니다.
- DOCX와 HWP는 기존 네이티브 텍스트 파서 경로라 OCR 문자 정확도 분모에 넣지 않았습니다.
- 정답 문자 29,425자는 공백/서식 제외 및 명시된 정규화 후의 문자 수입니다.
- 사진 내부, 바코드 패턴, 장식 요소, 읽을 수 없는 도장 인문은 제외했습니다. 읽을 수 있는 로고와 바닥글은 포함했습니다.
- 원본 PDF는 텍스트 레이어 없는 스캔이며, 내장 이미지 1241×1755를 기존과 동일하게 200 DPI PNG(1655×2340)로 렌더했습니다.
- VLM: PaddleOCR-VL-1.6, `use_ocr_for_image_block=False`. LLM: `qwen3.8-flash-next`.
- 1~16쪽: 기존 실행 결과를 재사용했습니다. LLM 문자 전사 실험은 별도로 재실행했습니다.
- 17~21쪽: 사용자가 선택한 범위에 맞게 같은 사진 사각형을 흰색으로 가린 입력으로 세 방식을 재실행했습니다.
- 입력 이미지 해시가 세 방식에서 일치함을 확인했습니다. 마스킹으로 주변 레이아웃 판단이 바뀔 수 있으므로,
  이 점수는 원본 사진 페이지의 무가림 실행 점수와 동일하지 않습니다.
- 기존 `<figure>` 설명은 제외하고 OCR 필드인 캡션/표기를 채점했습니다. 본문 추가 문구나 중복은 임의로 지우지 않았습니다.
- 대소문자·문장부호·숫자를 유지합니다. Unicode NFKC, 대시·따옴표·빈 체크박스 글꼴 통일을 적용했습니다.
- 정답 전사본은 기존 LLM 초안을 AI가 원본 이미지와 대조해 수정했습니다. 독립적인 사람 검수가 없어 잔여 오류와 초안 편향 가능성이 있습니다.

계산식은 `CER=(S+D+I)/N`, `정확도=100×(1-CER)`입니다.
[Hugging Face CER 정의](https://github.com/huggingface/evaluate/blob/main/metrics/cer/cer.py)와 같은 편집 거리 기준입니다.
전체 점수의 분자는 모든 페이지의 오류 합계이며 분모는 모든 페이지의 정답 문자 합계입니다.
자세한 전사 규칙과 페이지별 검토 기록은 [참조 전사본 안내](ocr_reference/kc_n5800/README.md)에 있습니다.

## 검증

채점기 12개 + 기존 OCR/사양서 연동 30개, 총 **42개 테스트 통과**.
치환·누락·삽입, 빈 입력, 100%를 넘는 CER, 문자 수 가중 합산, 한글/서식 정규화,
한국어 꺾쇠 캡션 보존, 중복 문자 유지, 누락 페이지 및 결과 변경 검출을 확인했습니다.
또한 100개 임의 짧은 문자열 쌍에서 독립적인 단순 DP 구현과 편집 거리가 일치했습니다.

```powershell
# 프로젝트 루트, 모델 재호출 없이 동일 결과 재채점
.\.venv\Scripts\python.exe tests/score_ocr_cer.py
.\.venv\Scripts\python.exe -m pytest tests/test_ocr_cer.py tests/test_ocr_backend.py tests/test_spec_import.py -q
```
