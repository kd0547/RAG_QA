# KC N5800 전체 문자 참조 전사본

원본: `tests/data/KC인증서_안전확인_신고증명서_노트북_컴퓨터_N5800_20260107.pdf`, 21쪽.
정답 파일은 `page_001.txt`부터 `page_021.txt`까지이며 파일별 해시와 검토 기록은 `manifest.json`에 있습니다.

## 작성과 한계

1~16쪽은 기존 LLM OCR 결과를 초안으로 사용하고 Codex가 원본 21쪽 이미지를 시각적으로 확인하면서
오인식, 누락, 생성된 설명, 서식을 수정했습니다. 17~21쪽의 머리글과 캡션은 원본을 보고 전사했습니다.
이 자료는 **AI 보조 원문 대조 전사본**입니다. 별도 사람이 독립 전사하거나 교차 검수한 정답은 아닙니다.
특히 LLM 결과에서 시작한 초안의 오류가 남아 있으면 해당 방식에 유리한 편향이 생길 수 있습니다.
점수는 이 고정 전사본에 대한 재현 가능한 측정값이며 공인 정확도가 아닙니다.

## 전사 범위와 순서

- 모든 본문·표·머리글·바닥글·페이지 번호·캡션, 읽을 수 있는 로고 문자 포함.
- 사용자가 제외한 사진 내부의 배터리/기판 라벨·자 눈금은 제외. 17~21쪽 사진 영역은 모든 모델의 입력에서 동일하게 가렸습니다.
- 바코드/2D코드의 점 패턴, 장식 테두리, 판독할 수 없는 도장 인문은 제외. 코드 아래의 안내 문장은 포함.
- 위에서 아래로 문서 블록을 읽고, 표는 행 우선/왼쪽 셀부터 전사. 셀 안의 여러 줄은 이어 읽습니다.
- 병합 셀은 첫 해당 행에 한 번 전사. 취소선으로 지운 값과 새 값은 모두 포함합니다.
- 철자·대소문자·문장부호·원본의 오기를 보존합니다. 예: `Thinkness`, `componet`, `ciritical`, 16쪽 `N5800-GD70-PU01`.
- 17~18쪽 `ZH10003-20001I`의 마지막 글자는 수정차수 I로 전사했습니다. 세로 획이 비슷한 숫자 1과의 혼동은 오류로 남겼습니다.

## 채점 규칙

`CER = (치환 S + 누락 D + 삽입 I) / 정답 문자 N`, `문자 정확도 = (1 - CER) × 100`.
정확한 Levenshtein 최단 편집 거리를 구합니다. 같은 거리의 정렬이 여러 개면 일치→치환→삭제→삽입 순서로 선택합니다.
따라서 총 오류 수는 최단 거리이고 S/D/I 분해는 이 고정 규칙에 따릅니다. 삽입이 많으면 CER은 100%를 넘을 수 있으며 점수를 0으로 잘라 숨기지 않습니다.

주 지표는 공백을 제외합니다. 한글 완성형을 포함한 Unicode NFKC 정규화로 `㎜/mm`, `㎟/mm²`, 위첨자 등을 통일하고,
인쇄상 대시·따옴표와 빈 체크박스 `☐/□`의 글꼴 차이도 통일합니다. 대소문자와 나머지 숫자·기호·문장부호는 보존합니다.
연속 공백/탭/줄바꿈을 한 칸으로 정리한 공백 포함 점수도 별도로 기록합니다.
문자 순서가 바뀌면 삭제/삽입으로 계산하므로, 이 CER에는 읽기 순서 오류도 포함됩니다.

OCR 출력에서는 Markdown 제목/표/강조/취소선 서식과 실제 HTML 태그, LaTeX 표현 서식만 벗깁니다.
`<성적서 번호 ...>` 같은 원문 캡션은 보존합니다. `[이미지]`, `[2D코드]` 등 비문자 자리표시는 제거하며,
`[로고: ...]` 안의 글자는 유지합니다. `[판독불가]`는 오류로 계산합니다.
기존 LLM의 `<figure>` 안에서는 설명용 `내용`을 제외하고 `캡션/표기/구성`을 유지합니다.
본문에 덧붙인 강조 설명이나 같은 캡션을 두 번 쓴 결과는 그대로 삽입 오류로 계산하며, 정답을 보고 중복을 지우지 않습니다.

채점기: `tests/score_ocr_cer.py`. 네트워크/모델 호출 없이 저장된 결과를 다시 평가합니다.
원본 PDF, 전사본, OCR 출력 해시와 21쪽의 연속성, 백엔드 간 입력 이미지 일치를 검증합니다.

공식 지표 설명: [Hugging Face Evaluate CER](https://github.com/huggingface/evaluate/blob/main/metrics/cer/cer.py).
